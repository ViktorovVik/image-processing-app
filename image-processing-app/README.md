# Обработка изображений — учебная практика, вариант №7

Десктоп-приложение на Python (Tkinter + OpenCV) для простой обработки изображений.

## Возможности

- загрузка изображения из файла PNG или JPG;
- фотоснимок с веб-камеры;
- показ выбранного изображения в окне приложения;
- показ красного, зелёного или синего канала изображения;
- негатив изображения;
- вращение изображения на угол, введённый пользователем;
- рисование красного круга по координатам центра и радиусу, введённым пользователем;
- сброс изменений и сохранение результата в PNG или JPG.

На каждое действие приложение отвечает сообщением в строке состояния.
Некорректный ввод (буквы вместо чисел, пустые поля, значения вне допустимого
диапазона, повреждённые файлы, недоступная камера) не приводит к сбою: приложение
объясняет ошибку в диалоговом окне и продолжает работу.

## Требования

- Python 3.9 или новее с модулем `tkinter`;
- библиотеки из файла `requirements.txt`: `opencv-python`, `numpy`;
- доступ в интернет на время установки библиотек.

`tkinter` входит в установщик Python для Windows и macOS с сайта python.org.
В Linux он ставится отдельным пакетом:

```sh
sudo apt install python3-tk python3-venv      # Debian, Ubuntu
sudo dnf install python3-tkinter              # Fedora
```

## Быстрый запуск

Скрипты создают виртуальное окружение `.venv`, устанавливают зависимости
(только при первом запуске) и запускают приложение.

Windows (командная строка или PowerShell):

```bat
run.bat
```

Linux и macOS:

```sh
sh run.sh
```

## Сборка и запуск вручную

Все команды выполняются в каталоге проекта.

### Windows

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

### Linux и macOS

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

В командах интерпретатор окружения вызывается по полному пути, поэтому
активировать окружение не обязательно. При желании его можно активировать:
`.venv\Scripts\activate` в Windows или `. .venv/bin/activate` в Linux и macOS.

Точные версии всех установленных библиотек можно зафиксировать командой
`python -m pip freeze`, выполненной в окружении.

## Использование

1. Нажмите «Открыть файл (PNG, JPG)…» и выберите изображение, например
   `examples/sample.png`, либо нажмите «Снимок с веб-камеры».
   Если камер несколько, выберите номер камеры в поле «№» (по умолчанию 0).
2. Изображение появится в правой части окна. В строке состояния внизу
   показываются результат последнего действия, координаты пикселя под
   указателем мыши, размер изображения и масштаб показа.
3. Блок «Цветовой канал»: выберите «Красный», «Зелёный» или «Синий», чтобы
   увидеть один канал; «Все каналы» возвращает обычный вид.
4. Блок «Негатив»: кнопка «Показать негатив» инвертирует цвета.
   Повторное нажатие возвращает прежние цвета.
5. Блок «Вращение»: введите угол в градусах и нажмите «Повернуть» или Enter.
   Положительный угол — поворот против часовой стрелки, отрицательный — по
   часовой. Допустимы дробные значения, диапазон от −360 до 360.
6. Блок «Красный круг»: введите координаты центра X, Y и радиус в пикселях и
   нажмите «Нарисовать круг». Щелчок по изображению подставляет координаты
   центра. Флажок «Закрасить круг» рисует закрашенный круг вместо контура.
7. «Сбросить изменения» возвращает исходное изображение, «Сохранить как…»
   сохраняет то, что показано в окне, в файл PNG или JPG.

### Примеры

| Действие | Ввод | Результат |
|---|---|---|
| Поворот | угол `90` | изображение повёрнуто на 90° против часовой стрелки |
| Поворот | угол `-12,5` | поворот на 12,5° по часовой стрелке, холст увеличен |
| Круг | X `400`, Y `300`, радиус `100` | красная окружность с центром (400, 300) |
| Круг с заливкой | то же и флажок «Закрасить круг» | закрашенный красный круг |
| Некорректный угол | `abc` | сообщение «Угол поворота должен быть числом…» |
| Некорректный радиус | `0` | сообщение о допустимом диапазоне значений |

## Если веб-камера не подключается

Приложение сообщит об ошибке и предложит пути решения:

1. Проверьте, что камера подключена и включена (не закрыта шторкой, не
   отключена клавишей на ноутбуке).
2. Закройте программы, которые могут занимать камеру: Zoom, Skype, Telegram,
   вкладки браузера.
3. Разрешите доступ к камере в настройках конфиденциальности операционной
   системы (в macOS — для приложения «Терминал»).
4. Если камер несколько, укажите другой номер камеры.
5. Обновите драйвер камеры; в Linux проверьте устройство `/dev/video0` и права
   доступа к нему.
6. Если камеры нет, загрузите изображение из файла.

## Тесты

Модульные тесты проверяют обработку изображений, проверку ввода, работу с
файлами и получение снимка с камеры (камера заменена имитацией):

```sh
.venv/bin/python -m unittest discover -s tests -t .        # Linux, macOS
.venv\Scripts\python -m unittest discover -s tests -t .    # Windows
```
